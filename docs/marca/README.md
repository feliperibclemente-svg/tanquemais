# Marca Tanque+

Gota de combustível com "+" e o nome **Tanque+**, redesenhados em vetor a partir da imagem
usada nas redes sociais. Os arquivos em `svg/` são a fonte; os `png/` são exportações prontas.

## Cores

| Uso | Cor | Observação |
|---|---|---|
| Verde da marca | `#1E9A66` | Gota, ícone do app, fotos de perfil, materiais |
| Verde de interface | `#178559` | Botões e links do app: texto branco com contraste 4,6:1 (WCAG AA) |
| Azul-marinho | `#141A2C` | Nome "Tanque+" em fundo claro |
| Fundo claro | `#F3F6F5` | Capas e imagem de compartilhamento |

Tipografia do nome: Inter ExtraBold convertida em curvas (não depende de fonte instalada).

## Arquivos

| Arquivo | Uso |
|---|---|
| `logo-horizontal` | Site, documentos, apresentações (fundo claro) |
| `logo-horizontal-negativo` | Fundos verdes ou escuros |
| `symbol` | Só a gota (espaços pequenos, marca-d'água) |
| `app-icon` (1024×1024) | Ícone do app; base para lojas de aplicativos |
| `avatar-redes` (1080×1080) | Foto de perfil: Instagram, Facebook, WhatsApp Business, LinkedIn, TikTok, X — a gota fica dentro do recorte redondo |
| `capa-redes` (1500×500) | Capa do X/LinkedIn; em outras redes, centralize o conteúdo (bordas podem ser cortadas) |
| `og-image` (1200×630) | Prévia do link ao compartilhar o site (já configurada no app) |

## Regras rápidas

- Não esticar, girar, mudar a cor da gota ou trocar a fonte do nome.
- Manter em volta do logo um espaço livre de pelo menos a largura do "+".
- Tamanho mínimo do logo horizontal: 96 px de largura na tela; abaixo disso, use só a gota.
